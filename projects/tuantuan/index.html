团团桌面陪伴机器人

TuantuanA desktop companion robot

一个放在书桌上陪伴你的小机器人：圆滚滚的，大小和一个碗差不多，用屏幕显示会动的眼睛，带摄像头和轮子。目前外形和内部结构已经设计完成，三维模型可以直接在网页上转动、拆开查看。

A little robot that keeps you company on your desk. It is round, about the size of a bowl, shows lively eyes on a screen, and has a camera and wheels. Its shape and inner structure are fully designed, and you can spin and take apart the 3D model right on this page.

怎么设计的How it was designed

  • 改一个数字，整台机器跟着变外形尺寸和零件位置都写在一张参数表里，程序据此自动画出全部零件并组装好。想调整设计，改几个数字就行，不用一个个零件重画。
  • Change one number, the whole robot followsSizes and part positions live in one parameter table, and a program draws every part and assembles the robot from it. Adjusting the design means changing a few numbers, not redrawing parts by hand.
  • 电脑先替你“试装”每次修改后，程序自动检查零件会不会互相顶住、能不能顺利装进去、摄像头和眼睛会不会被挡住，在打印之前就把问题找出来。
  • The computer test-fits it firstAfter every change, the program checks whether parts collide, whether they can actually be put together, and whether the camera or eyes are blocked, catching problems before anything is printed.
  • 打开网页就能看做好的三维模型直接放在网页上，任何人都能转动、透视、拆开来看，不需要安装专业软件。
  • See it in your browserThe finished 3D model runs right in the browser. Anyone can rotate it, see inside and take it apart, with no special software.

用代码做结构设计Designing in code

团团的结构主要用代码来描述：外形尺寸、零件位置和装配关系写在一份参数文件里，Python 脚本据此生成全部零件、组装成整机，再导出网页上看到的预览模型。改一个参数就能重新生成整台机器，并立刻重新跑一遍检查。

每个源文件和外购件模型都记录了哈希值，网页上的每一版预览都能追溯到生成它的那一版源码和参数。

Tuantuan's structure is described mainly in code. Overall dimensions, part positions and how parts fit together live in a parameter file, and Python scripts use it to generate every part, assemble the robot and export the preview model you see on this page. Change one parameter and the whole robot is regenerated and re-checked.

Every source file and vendor model is recorded with a hash, so each preview on the web can be traced back to the exact sources and parameters that produced it.
