团团桌面陪伴机器人

TuantuanA desktop companion robot

一个直径约 15 厘米、圆滚滚的桌面陪伴机器人，用屏幕画出会动的眼睛。目前处在整机装配设计阶段：整台机器由参数文件和 Python 脚本生成，并自动检查零件干涉和摄像头视线；三维模型可以直接在浏览器里旋转、透视和拆解查看。

A round desktop companion robot about 15 cm across, with lively eyes drawn on a screen. It is currently at the assembly-design stage: the whole robot is generated from a parameter file and Python scripts, with automatic checks for part interference and camera sight lines, and its 3D model can be rotated, seen through and exploded right in your browser.

用代码做结构设计Designing in code

团团的结构主要用代码来描述：外形尺寸、零件位置和装配关系写在一份参数文件里，Python 脚本据此生成全部零件、组装成整机，再导出网页上看到的预览模型。改一个参数就能重新生成整台机器，并立刻重新跑一遍检查。

每个源文件和外购件模型都记录了哈希值，网页上的每一版预览都能追溯到生成它的那一版源码和参数。

Tuantuan's structure is described mainly in code. Overall dimensions, part positions and how parts fit together live in a parameter file, and Python scripts use it to generate every part, assemble the robot and export the preview model you see on this page. Change one parameter and the whole robot is regenerated and re-checked.

Every source file and vendor model is recorded with a hash, so each preview on the web can be traced back to the exact sources and parameters that produced it.

装配中使用的是厂商公开的机械参考模型，部分做了简化；尺寸还需要对照实物复核。 The assembly uses vendors' published mechanical reference models, some simplified; dimensions still need to be checked against the real parts.

进展Status

当前版本为 v1.0.0（2026 年 10 月 8 日），完成了整机装配设计和上面的自动检查。下一步是打印零件、实物试装，验证装配和功能；装配说明和固件完成后，会整理发布完整的 V1 套件。

The current version is v1.0.0 (October 8, 2026), with the full assembly designed and passing the checks above. Next comes printing the parts and test-fitting a real prototype to validate the fit and function; once the assembly guide and firmware are done, the complete V1 kit will be released.
