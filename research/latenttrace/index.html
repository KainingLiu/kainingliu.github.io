研究内容Research

用参数化向量库作为记忆媒介，探究具有原生记忆能力的 AI 模型。

Using a parameterized vector store as the memory medium to explore AI models with native memory.

今天的大模型只有一种记忆：上下文里的文本。对话越长，上下文越长，计算越慢越贵，最终受窗口长度限制。外挂的记忆系统（如检索增强）把“存什么、什么时候取”交给人写的规则或另一个模型，记忆管理并不在模型自身的学习之中。

Today’s LLMs have only one kind of memory: the text in their context. The longer the history, the longer the context, the slower and costlier the computation, until it hits the window limit. External memory systems such as retrieval augmentation leave what to store and when to fetch it to hand-written rules or a separate model, so memory management is not part of what the model itself learns.

本课题让模型拥有一块由向量组成、可以持续增长的记忆：

This project gives the model a growing memory made of vectors:

  • 写入的是理解，而不是原文：模型把自己处理信息时的内部表示存入向量库；
  • 存取由模型自己学会：什么时候存、存什么、什么时候回忆，都是模型在训练中学到的行为，不依赖外部检索器或人工规则；
  • 清空上下文后仍能作答：原文离开上下文之后，模型可以凭向量记忆继续回答相关问题；
  • 对原模型改动尽量小：能直接沿用预训练模型和已有的训练、推理流程。
  • It stores understanding, not raw text: the model writes its own internal representations into the vector store.
  • The model learns to use it: when to store, what to store and when to recall are behaviors learned in training, with no external retriever or hand-written rules.
  • It answers after the context is cleared: once the original text has left the context, the model can still answer from its vector memory.
  • Minimal changes to the base model: pretrained models and existing training and inference pipelines can be reused.
