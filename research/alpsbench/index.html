研究内容Research

大模型正在成为长期陪伴用户的助手，个性化能力越来越重要，但缺少一个可靠的评测标准：已有基准要么不考察个性化信息的管理，要么使用和真实对话差别很大的合成对话。

As LLMs become long-term assistants, personalization matters more and more, yet there is no reliable yardstick: existing benchmarks either ignore how personal information is managed or rely on synthetic dialogues that differ from real conversations.

AlpsBench 基于 WildChat 中的真实人机对话，构建了 2,500 条长期交互序列，并为每条序列配上人工核验的结构化记忆，覆盖个性化信息从产生到使用的完整过程，共四项任务：

AlpsBench is built from real human–LLM dialogues in WildChat: 2,500 long-term interaction sequences, each paired with human-verified structured memories. It covers the whole life cycle of personal information through four tasks:

  • 抽取：从对话中识别用户的特征与信息；
  • 更新：用户信息变化时修正已有记忆；
  • 检索：找出与当前对话相关的记忆；
  • 利用：用记忆生成贴合用户偏好的回答。
  • Extraction: identify user traits and information in dialogue.
  • Updating: revise stored memories when user information changes.
  • Retrieval: find the memories relevant to the current conversation.
  • Utilization: use memories to produce responses aligned with the user’s preferences.

在前沿大模型和记忆系统上的评测发现：模型难以可靠地抽取隐含的用户特征；记忆更新即使在最强的模型上也存在明显瓶颈；干扰记忆很多时检索准确率大幅下降；显式记忆机制能提高回忆率，但不一定带来更贴合偏好、更有共情的回答。

Evaluations of frontier LLMs and memory systems show that models struggle to extract latent user traits reliably; memory updating hits a ceiling even for the strongest models; retrieval accuracy drops sharply with many distractor memories; and explicit memory improves recall but does not guarantee more preference-aligned or empathetic responses.
