华为小艺个性化记忆智能体Personalized Memory Agent for Huawei XiaoYi

科研实习生 · 中国科大数据科学实验室（LDS）× 华为小艺Research Intern · Lab for Data Science (LDS), USTC × Huawei XiaoYi

2026.02 – 2026.052026.02 – 2026.05

研究内容Research

为华为小艺 AI 助手开发个性化大模型记忆系统：从用户与助手的对话中抽取值得长期记住的信息，存入记忆，并在之后的交互中检索出来，让助手的回答更贴合用户本人。

A personalized LLM memory system for the Huawei XiaoYi AI assistant: it extracts information worth remembering from user–assistant conversations, stores it, and retrieves it in later interactions so the assistant’s replies fit the user better.

我负责的工作My Role

  • 设计并实现记忆抽取智能体流水线；
  • 对记忆抽取与检索行为进行实验评估与分析；
  • 撰写技术报告与实验文档。
  • Designed and implemented the memory-extraction agent pipeline.
  • Evaluated and analyzed memory extraction and retrieval behavior.
  • Wrote technical reports and experiment documentation.
