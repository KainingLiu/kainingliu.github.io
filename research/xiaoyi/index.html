华为小艺个性化记忆智能体Personalized Memory Agent for Huawei XiaoYi

科研实习生 · 中国科大数据科学实验室（LDS）× 华为小艺Research Intern · Lab for Data Science (LDS), USTC × Huawei XiaoYi

2026.02 – 2026.052026.02 – 2026.05

项目介绍About the project

“小艺”是华为手机上的 AI 助手。我们和华为合作，为它开发了一套记忆系统，让它更像一个了解你的老朋友：能从日常聊天中记住你的喜好和重要信息，下次交流时自然地用上，给出更贴合你本人的回答。

XiaoYi is the AI assistant on Huawei phones. Working with Huawei, we built a memory system that makes it more like an old friend who knows you: it picks up your preferences and important details from everyday chats and uses them naturally next time, so its answers fit you personally.

负责部分My Role

  • 决定“该记住什么”：设计并实现自动提取流程，从用户与助手的对话中挑出值得长期记住的信息；
  • 检验效果：测试并分析这套系统记得准不准、需要时能不能找对；
  • 整理文档：撰写技术报告和实验文档。
  • Deciding what to remember: designed and built the pipeline that picks out information worth keeping from user–assistant conversations.
  • Checking that it works: tested and analyzed whether the system remembers accurately and finds the right memory when needed.
  • Documentation: wrote the technical reports and experiment documentation.
